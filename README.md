# Gem Tycoon

A single-file browser economy game. Open `index.html` in any browser, including on a phone. It has no build step and no dependencies.

You get 50 rounds and 1000 starting gold. Buy mines (which produce uncut gems or silver) and jewellers (which cut gems into sapphires or diamonds), upgrade them, and sell goods. The goal is to finish with the most gold. The full rules are in the in-game "Rules" panel. All the tunable numbers are in the `CFG` object at the top of the script.

The leaderboard (top 10) and the game in progress are saved in the browser's localStorage.
